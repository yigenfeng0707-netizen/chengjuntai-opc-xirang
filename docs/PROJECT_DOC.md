# 成军台 · 项目文档（BP 摘要）

## 1. 一句话

成军台是面向超级个体（OPC）的 AI 原生操作系统：输入目标，在中国电信息壤/星辰 TokenHub 上调度多 Agent 协同完成调研、内容、问数、运营与复盘，让一个人顶一支小队。

## 2. 问题 → 方案 → 演示（评委路径）

| 痛点 | 成军台解法 | 演示点哪里 |
|------|------------|------------|
| 一人公司获客/运营无人可用 | 目标驱动战役 + AI 员工矩阵（调研/内容/问数/运营/复盘） | 成军看板「发起成军」· 模板「AI获客跟进」 |
| Chat 套壳难验收 | 人审卡点 + 产物抽屉可预览 | 打开战役 → **打开产物 / 预览** |
| 对内同步缺交付物 | 成军周报 **导出 Word**（主）/ MD·PDF（次） | 战役完成 → **导出 Word** |
| 市场情报靠猜 | 智能问数连 SQLite 演示库 / NL2SQL MCP | 侧栏「智能问数」；`scripts/start_nl2sql_demo.bat` |

样例快照：启动时写入 2～3 个已完成战役（`scripts/seed_demo_campaigns.py`），避免空看板。

## 4. 创新点

1. 产品即赛事口号「一人成军」，不是通用聊天套壳
2. 目标驱动任务树 + 人审卡点，可验收、可追溯
3. 默认对接主办方底座（息壤/星辰），失败可见、禁止静默 mock
4. 复用并升维已有 NL2SQL + 内容工厂生产能力；周报以 Word 为演示主交付

## 5. 技术架构

Web（成军看板）→ 司令 Agent → 战役状态机 → 角色 Agent（research/content/data/ops/review）→ llm_client（息壤主 / 商汤·百炼备）→ 成军周报 Word/PDF；数据参谋可选 NL2SQL MCP（8765）+ znws（8082）+ `bid_telecom.db`。

## 6. 商业模式

- 个人/工作室订阅（按月）
- Token 用量（智云 Store / 星辰 Token 套餐）
- 政企轻咨询与模板战役包

## 7. 社会价值

降低个体创业者「招不起团队」的门槛，用 AI 员工矩阵普惠数字化经营能力。
