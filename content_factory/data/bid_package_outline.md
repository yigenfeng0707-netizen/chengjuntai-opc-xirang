# 投标文件章节大纲（通用模板）

> 结构参考云资源类「整套投标包」常见分册（脱敏通用版）。导出 Word 时由标书工作台附卷；正式文本须替换项目名/客户名并经商务法务终审。

## 0. 投标文件总目录

### 第一册 商务文件

1. 投标函
2. 法定代表人身份证明
3. 法定代表人授权委托书
4. 非联合体投标承诺函（如适用）
5. 商务条款响应表
6. 报价策略与报价文件
   - 6.1 报价策略说明
   - 6.2 报价汇总表

### 第二册 技术文件

7. 项目理解
8. 总体技术架构
9. 核心服务方案（按招标范围裁剪：云算力 / 网络 / 平台 / AI 等）
10. 数据与存储方案（如适用）
11. 安全与合规方案（等保、WAF、监测、应急等按评分点展开）
12. 实施计划与里程碑
13. 验收方案
14. 售后服务与运维保障
    - 14.1 服务承诺
    - 14.2 服务团队
    - 14.3 故障响应机制

### 第三册 业绩佐证与资质材料

15. 资质材料清单
16. 同类业绩摘要表
17. 业绩证明装订建议

### 第四册 合规自检与评分策略

18. 技术参数点对点响应表
19. 废标风险清单
20. P0 / P1 / P2 整改优先级
21. 评分攻坚表（得分点 → 证据页码）
22. 最终提交前检查清单

### 第五册 策略结论（内部）

23. 综合投标策略
24. 评审感知要点
25. 提交决策结论

## 与成军台工作流对齐

| 大纲块 | 成军台动作 |
|--------|------------|
| 要求拆解 / 响应表 | 标书工作台「粘贴招标 → 要求清单」 |
| 证据 / 缺口 | 「对照知识库 → 证据矩阵」 |
| 证明稿补齐 | 内容工厂 / 获客·综述战役 → 推入标书知识库 |
| 本大纲 + 清单 + 矩阵 | `/api/bid/workspace/export_docx` 导出 Word |
